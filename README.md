# Checktrail

## Folders that matter

- **`public/ui/`** — placeholder UI (HTML/CSS/assets) + diegetic Three.js. Friend replaces this.
- **`public/ui/preview/`** — open `/ui/preview/` to orbit room + player4 GLBs.
- **`public/logic/`** — game + Supabase logic. Don’t edit for visual redesigns.
- **`app/page.tsx`** — thin hub shell; styles in `public/ui/hub/hub.css`.

See `public/ui/README.md` and `public/ui/CONTRACT.md` before swapping UI.
